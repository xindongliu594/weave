# 07 安全、权限与成本

## 密钥

- 浏览器不读取、保存或展示完整 API Key。
- 后端加密保存密钥，只向 Runtime 注入短生命周期凭证或运行时环境引用。
- 日志、错误、快照、消息和交付物统一执行敏感信息脱敏。
- Credential 删除后禁止新调用；已有运行转为失败或等待用户处理。

## 权限模型

最小权限默认值：

- 文件系统：仅部门工作区。
- 网络：默认关闭，按工具或域名开放。
- Shell：沙箱内执行。
- 外部写：必须批准。
- 知识库：显式 Grant。
- 子 Agent 深度：MVP 固定为 0，成员不能继续创建成员。

## 必须审批的操作

- 删除、覆盖或移动重要文件。
- Git push、发布、部署。
- 发送邮件、消息和创建外部工单。
- 修改外部数据库或 SaaS 数据。
- 提升权限或新增网络目标。
- 预计导致 Run 超预算的继续执行。

审批记录必须包含请求者、工具、参数摘要、风险、批准人、时间和最终结果。

## 成本控制

限制维度：

- 单模型调用 Token 上限。
- 单 Agent 每任务最大轮数。
- 单任务、单 Run、单部门每日费用。
- 同时运行的 Agent 数量。
- 模型和工具超时。
- 重复失败熔断。

系统要区分预算“软提醒”和“硬停止”。硬停止后不再启动新模型调用，但允许保存当前结果和状态。

### 规划预算

- 规划本身设置独立上限，默认不超过总预算的 10%。
- 主模型输出的费用只是估算，后台依据模型价格目录重新计算。
- 建议预留：执行 70%、验证 15%、重试 5%；具体比例可由策略调整。
- 达到总预算 70% 时发出提醒；90% 时禁止新增 Agent 和非必要重试；100% 时硬停止新调用。

### 自动模式门槛

全自动运行仅在以下条件同时成立时开放：

- 方案通过最新的确定性校验。
- 风险等级为低。
- 不包含外部写、部署、发送或删除操作。
- 预计费用低于自动批准阈值。
- 模型和知识授权在批准前未变化。

## 审计

至少保存：

- 谁创建/修改了部门和员工。
- Run 使用的不可变配置快照。
- 每个模型请求的 Provider、模型、Token、延迟和费用。
- 每个工具调用的输入摘要、批准状态和结果。
- 每次模型切换、任务改派、重试、取消和恢复的原因。

## 威胁清单

- 文档中的 Prompt Injection。
- Agent 越权访问其他部门知识。
- 工具参数注入和命令拼接。
- 日志泄漏密钥或私人文档。
- 多 Agent 同时写同一文件。
- 恶意任务制造无限循环或费用消耗。
- DSH 管理端口暴露。

所有工具在执行侧再次鉴权，不能只相信模型提示词中的限制。
