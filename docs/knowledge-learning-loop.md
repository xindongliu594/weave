# 为伍：工作、复用与能力沉淀闭环

状态：2026-10-09 与用户确认的下一阶段需求；本文不是功能已实现或验收通过的声明。

## 核心流程

任务 → 检索获授权的公司知识、Skill 与工具目录 → 员工判断适用性并选择 → 按需加载 → 执行、测试、验收 → 登记工作及引用 → 后续任务复用 → 提炼经验或能力候选 → 验证、发布。

用户确认目标、权限和预算。员工自行检索、选择已有方法；手动指定方法是可选入口。检索与加载不授予新的工具、资料或预算权限。

## 命中与未命中

- 完全适用：复用已有内容，固定其版本，关联本次工作与实际采用的内容。
- 部分适用：复用适用的步骤或片段，记录改动和新步骤，关联原始来源；无需复制整份流程再计为一份独立经验。
- 无适用结果：按新任务流程完成开发、独立测试和验收，登记新工作的方案、问题、解决方式与证据。未命中仅表示当前获授权范围内没有找到适用结果，不能断言全公司不存在。
- 执行失败：仍登记失败案例、条件和失败证据；不能作为成功方法自动发布。

登记以为伍现有持久工作记录为事实来源，保存任务、员工、部门、尝试、交付文件和真实测试结果的关联。新流程先是工作记录或经验候选，不会因模型写了一段总结就成为可信 Skill。

## 什么算复用

区分检索命中、读取、实际采用和验证成功。检索次数、重复读取、同一任务续跑均不能冒充多次成功复用。

实际采用记录须包含来源记录/文档、固定版本、所采用的步骤或片段、本次任务与执行尝试、验证结果。一次工作可以引用多个来源，一个来源可以被多个工作复用。

沉淀依据是不同工作中多次实际复用及其效果。具体阈值可配置，不在此次需求确认中擅自设定固定次数。达到条件后自动生成候选，保留失败率、适用条件、反例和测试证据；不单凭次数自动发布能力。

## 沉淀的不同形态

| 形态 | 适用内容 | 发布所需证据 |
| --- | --- | --- |
| 经验 | 问题、原因、判断、约束和解决原则 | 来源可追溯，成功与失败条件清楚 |
| Skill | 能跨任务复用的工作步骤、检查项和方法 | 多次实际采用，步骤完整，经理审核或明确发布策略 |
| 工具 | 输入、输出与行为稳定的可执行操作 | 隔离执行、独立测试、权限审查、固定版本及撤销入口 |

三个形态不是强制升级链。经验可以长期保持为经验；适合指导员工的内容成为 Skill；适合确定性执行的内容才成为工具。发布审核沿用经理、独立 QA 和产品审批规则，避免把每次选择都交给用户。

## 恢复、权限与容量

- 工作登记和引用统计采用持久事件及幂等标识；重启补记，恢复同一任务不重复计数或重复登记。
- 执行中的引用固定版本；新发布的经验供后续任务检索，不静默替换当前任务的已批准上下文。
- 来源保留公司、部门和员工权限；提炼、转交、删除与复用均不能使私有资料自动公开。
- 工作记录引用已有交付文件、测试日志和文档版本；摘要去重，避免再保存一套完整对话与原始文件。
- 清理保护活动任务、恢复检查点、未知外部操作及发布能力的证据；暂存与失败现场按保留策略回收。

## 长任务目标保护

用户已确认这项功能也须实现。保留现有批准快照、每步任务合同注入和交接门禁，增加阶段性目标偏离检查与纠偏记录。

- 固定目标、范围、交付物、验收标准与预算的版本；员工可提出做法调整，但不能为通过验收自行改写目标或降低标准。
- 检索到的知识、历史经验和 Skill 是任务资料，不得覆盖任务合同；摘要不能替代文件与命令证据。
- 在节点开始、交付提交、连续失败与恢复等边界核对当前工作对应的验收标准。规则能判断的条件先在本地检查，语义判断由经理在必要边界完成，避免每次工具调用额外请求一个评审模型。
- 发现无关扩展、重复动作或无法证明进展时，记录原因并有限返工；越界、超额或需要变更目标时沿用现有暂停与审批规则。
- 恢复沿用正确合同版本、DAG 和原始证据，重建剩余任务。经验候选关联原目标和真实验收结果，防止把偏离目标的结果误记为成功经验。

这套保护降低偏离影响，不保证模型永远不偏离。验收应主动注入无关 Skill、错误摘要、范围外建议和虚假完成声明，证明其不会覆盖目标或绕过门禁。

## 复用现成组件与实施顺序

DSH 官方目录和 Skill 加载器负责员工发现与按需读取；MCP 承载已启用的外部工具。为伍负责公司权限、工作引用、成功复用统计、审批、版本和恢复规则。记忆插件继续通过隔离兼容性与恢复验证后再接生产，不自行另造通用记忆核心。

1. 将已批准的公司/部门方法接入员工可见目录，复用现有知识授权、检索与固定版本。
2. 接通持久工作登记与实际引用记录，验证未命中、部分复用、成功复用以及重启去重。
3. 接入记忆插件整理候选；按实际复用证据区分经验、Skill 和工具，经过验证发布。
4. 网页展示来源、引用工作、验证结果、候选和发布状态，再用一个小任务验证整个闭环。

当前已接通运行内批准 Skill 的官方目录和加载器；公司级自动发现、工作沉淀闭环、复用统计与能力晋升仍待实现。开发回归优先本地验证，真实模型调用沿用已批准预算。
