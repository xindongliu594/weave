# 模型能力验证

模型目录把文本连通与工具调用分别显示。DSH 团队调度本身依赖工具调用，即使员工没有配置文件或终端工具，主模型和备用模型也要通过工具往返测试，才能批准执行。编辑部门、保存草案和预览组织不要求已通过工具测试。

在模型目录先测试连接，再点击“测试工具能力”。每次最多两次模型请求：第一次要求调用无副作用的测试函数并传回指定参数，第二次提供本地生成的工具结果，要求模型正确读取。不会执行文件、终端或外部服务操作。测试通过只证明当前配置完成过该协议检查，不保证之后所有复杂任务都成功。

默认总费用上限为 0.10 USD，可在页面调整（最高 10 USD）。两次请求各分配一半上限，并受全局日预算约束；价格沿用模型目录配置。预算不足会在请求前拒绝。中转站未返回用量时保留待核对费用，不标记能力通过。记录可在“查看能力测试记录”查看，费用在用量页核对。不会自动向真实模型发起能力测试。

能力结果由服务端测试写入，不能通过编辑模型声明“支持”。修改模型或中转站配置后，文本与工具测试均需重做。批准快照固定模型配置和中转站版本的指纹；配置变化后即使重新测通，旧批准仍须重新制定并批准，不能用新路由继续旧运行。启动、重试和后续模型请求都会检查当前证据和指纹。升级前没有指纹的旧运行可查阅历史，但不能直接重试。

测试期间备份和恢复会提示等待，避免导出进行中的不完整证据。测试记录、能力结果和用量随加密备份保留；旧版备份无能力记录时恢复为“尚未验证”。中断的测试会在后台过期后标记中断，相关未知费用仍需核对。
