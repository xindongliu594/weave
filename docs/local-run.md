# 本机运行与真实 API

2026-10-02：增加适用于当前电脑的单用户本机入口。使用持久 PGlite 数据库和已有的 Node 本机执行组件，不需要 Docker 或线上部署。模型连接采用原有真实中转站、费用与工具调用路径；不启动固定响应模型，不安装演示执行器。

## 启动

需要 Node.js `^22.19.0 || >=24`。依赖已安装时直接启动：

```sh
npm run local
```

首次安装依赖：`npm ci`、`npm --prefix services/agent-runtime ci`。Windows 也可双击仓库根目录的 `start-local.cmd`。打开 `http://127.0.0.1:4310/#models`；端口占用时使用 `npm run local -- --web-port=4312`，不会停止其他服务。

## 配置并使用真实模型

1. 在“模型目录”接入中转站，填写 Base URL 和自己的 API Key。Base URL 为完整 API 前缀，不含 `/chat/completions`。
2. 点击“保存并获取模型与价格”，选择需要的模型。默认按已核对的 OpenAI 官方公开价格填写，页面显示核对日期和档位；无法精确匹配的模型手动填价。按需调整上下文容量，见 [模型目录与自动填价](model-catalog.md)。
3. 中转站卡片可先点击“测试 API 服务”，检查当前连接的模型目录、耗时和失败原因，不调用模型推理。添加模型后再点击模型卡片的“测试连接”和“测试工具能力”，确认真实文本和工具往返；这两类测试以及生成/执行任务会发起模型请求，由所配置的服务计费。保存配置不自动调用模型。
4. 创建部门和员工，分配模型与工具；保存项目并检查方案。新项目默认选中“本机 Node 执行器”，文件和命令在本机工作区执行。组织创建/预览入口也使用这个默认值，显式选择 Docker 或另一台设备时尊重用户选择。
5. 批准方案，在执行页逐次批准命令，查看实际测试结果、文件版本、审查和交付物。实现任务仍需独立审查，沿用原有合同、权限、预算和异常停止规则。

这里“本机运行”指后台、数据库、文件和命令在当前电脑；模型计算由你配置的 API 服务完成。可以连接兼容的本地推理服务，但启动器本身不提供推理模型。

## 数据与停止

默认数据保存在 `.data/local`，重启保留，不与 `.data/demo/<UUID>` 的演示数据混用。需要从另一份代码启动已有本机空间时，可显式指定原数据目录的绝对路径，例如 Windows PowerShell：

```powershell
npm run local -- '--data-dir=C:\Users\JJ\Desktop\la\agent_department\.data\local'
```

先停止访问这个数据目录的原服务。启动锁会拒绝双开，不复制或覆盖数据库、密钥与设备凭证；项目工作区仍在原目录中，原目录授权继续核验。参数不能指向仅包含数据库的子目录，也不能用相对路径。`local:check` 禁止 `--data-dir`，始终在独立检查目录验证。数据目录包含：

- `database`：模型目录、部门、项目、费用和操作记录。
- `credentials`：用于加密模型 Key 和设备凭证的主密钥；`device.credential` 为加密后的设备配置。
- `workspaces/<Run ID>`：每个项目运行独立的本机文件工作区。
- `runs`：审批、会话、完整追溯和已验收成果镜像；`journal` 保留本机操作回执，重启不会自动重放已有命令。

Ctrl+C 关闭网页、API、员工 Host、本机执行组件和数据库，文件保留。启动锁阻止同时打开两套服务访问同一个数据库。若在页面停用本机设备，重启不会暗中恢复该授权；配置页面仍可访问。需要重新授权时，停止服务后运行 `npm run local -- --enable-device`，这会创建新的设备和目录授权；旧项目需要在方案中重新选择在线设备、保存并批准。

当前入口用于单用户本机雏形，PGlite 只有一个数据库后台，不能据此宣称真实 PostgreSQL 多连接锁或多人部署已通过验证。原有 PostgreSQL/Docker 的 `npm run dev` 入口继续保留。

## 检查

```sh
npm run build
npm run local:check
```

`local:check` 在 `.data/local-check/<UUID>` 中创建独立空间，使用明确标记的固定协议测试服务，不调用付费模型。检查外部 API 地址可保存、凭证不回显、新项目默认绑定真实本机设备、非预置文件实际写入、命令在批准后运行并生成结果、成果回传下载，以及 API 重启后配置和设备授权保留且完成任务不重放。检查不会向正常 `.data/local` 添加测试配置，不代表某个真实模型已通过业务验收。
