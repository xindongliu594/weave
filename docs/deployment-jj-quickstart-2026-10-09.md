# 在网页使用 JJ 上的为伍

2026-10-18 的原生办公插件与网页连接补充见 [当前使用说明](jj-web-quickstart-2026-10-18.md)。本文后面的试点金额为当时历史授权，不能替代后续批准的额度。

Windows 使用浏览器，JJ 保存部门、项目、知识与交付文件。JJ 服务退出登录后继续保活；这不等于部门已经可以无限期自主接单。

## 打开

在本项目 PowerShell 执行 `./scripts/deployment/connect-jj.ps1`，打开脚本输出的地址，默认 `http://127.0.0.1:4312/`。已有本次专用隧道时直接访问即可；不要再启动一份同端口隧道。也可以指定 `-LocalPort 4313`。

首页是“部门工作台”。选择部门可看待办、执行中、待处理和交付；“需求与方案”可以回到项目编辑。历史失败和历史交付分别保留。

## 完成一个小项目

1. 新部门从“需求组建”开始，多轮说明目标和补充约束，确认方案后才保存部门、员工和项目。已有部门从工作台录入新需求，先保存为待办，再进入需求与方案。
2. 核对模型、任务、预算与授权。当前已有 Go / DeepSeek 配置，Key 保存在后端；不需要手改数据库。
3. 如果需要隔离开发，在项目方案的执行设备中选择 **OpenShell 隔离执行设备**，保存并确认方案。原 native 设备仍保留，它使用 JJ 用户权限，不具备同样的 OS 隔离。
4. 批准执行。运行详情显示当前任务、员工、费用和命令审批；核对员工申请的具体命令后批准。
5. 到“真实测试结果”展开命令和原始输出。完成后从“交付物”预览或下载代码、测试和 README；运行方法以员工 README 为准。

例子可以很小：一个无第三方依赖的 Node.js 摄氏转华氏 CLI，由开发写程序和 README、独立 QA 写测试并执行、经理只读验收。已验证正常项目的用法是 `node cli.mjs 25`，测试命令是 `node --test cli.test.mjs`。

当前 JJ 实测结果可直接查看：[正常完成](http://127.0.0.1:4312/#run/6197cb6e-d63b-41e9-808e-3666bc376b84)及[停止后恢复完成](http://127.0.0.1:4312/#run/19acad23-c885-40cc-9fa7-df7d7ec127bf)。这些链接使用上述默认隧道端口；完整核对见[本轮验收报告](validation/phase1-phase2-delivery-2026-10-09.md)。

## 停止与继续

运行页点“停止运行”，等待状态结束。服务重启后打开原运行，点“检查恢复条件”，核对已完成任务数、原方案、已用调用与剩余预算，再选择“恢复未完成任务”并确认。

完成节点保留，未完成节点继续。完整重试仍受原方案累计调用次数约束；不能通过反复重试清零。未知费用可在保留预留的前提下继续原预算；结果未知的文件、命令等操作须先核对，不自动重放。恢复确认期间的费用刷新不会取消用户正在查看的确认面板。

## OpenRig 的入口

已绑定的试点部门在工作项上提供显式同步按钮，显示 OpenRig 工作项编号和队列状态。同步只登记有限项目元数据，不会启动第二套员工。结果未知时只能查询原编号，刷新页面也不会重复创建。

OpenRig 的队列状态与为伍经理验收分开展示。当前还未接通自动领取、终态关闭、多版本替换和持续自主调度；没有绑定的部门继续使用为伍原流程。

## 数据与维护

网页“系统设置 → 文件与数据容量”可查看容量、生成完成副本的清理预览，确认后逐文件回收。交付档案和恢复证据保留；中断后只核对，不自动续删。[使用方法与边界](storage-governance.md)

- 业务数据：`/home/jj/.local/share/weiwu/data/pilot`。
- OpenShell 独立设备资料：上述目录的 `openshell`；原 native 资料保留。
- OpenRig 元数据、数据库、token 与映射：上述目录的 `openrig`；不要提交这些私有文件到 Git。
- 服务：`weiwu-jj.service` 和可选 `weiwu-openrig.service`，均由 JJ 用户 systemd 管理。
- 网页加密备份覆盖为伍核心数据库、档案、交付与知识；当前不包含可选 OpenRig SQLite/config/token。完整机器迁移还需一致的目录备份，先停止相关服务，恢复实验只在隔离目录进行。

关闭 Windows 隧道只影响访问，JJ 服务继续运行。服务重启可用 `ssh jj 'systemctl --user restart weiwu-jj.service'`；先通过网页停止员工工作并核对在途操作，避免把维护重启当成外部请求已撤销。

原未知费用仍保留；本轮试点累计上限 $2、项目上限 $1.90，已发生费用计入。后续新增项目仍须遵守用户批准的总额度。连续 24 小时运行、休眠/断电故障、自动空间回收及跨机器完整迁移未在本轮宣称通过。
