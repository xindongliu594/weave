# 桌面本机文件与命令执行

2026-10-01，D1 第一批：用户在 Electron 桌面端选择父目录，后端仍协调独立员工 Host、模型、任务、审批、费用和运行档案；文件与逐次批准的命令交给所选设备实际执行。浏览器操作、桌面应用交互、读取现有任意文件目录尚未接入，完整 D1 仍未完成。

## 使用流程

1. 使用包含本机执行组件的新版桌面构建，先连接工作空间并填写登录账号。后端也须更新至相同版本。线上旧安装包与部署不会随源码合并自动更新。
2. 打开“工作空间 → 本机执行设置”，选择运行工作区的父目录并给设备命名。默认仅开放文件操作；需要终端时，单独勾选允许本机命令并启用设备。
3. 在项目执行策略中选择这台在线设备。方案保存、批准后冻结设备身份、目录授权、平台与命令能力；离线、停用或授权改变时拒绝执行，需要重新选择并批准。
4. 每个 Run 在父目录下创建以 Run ID 命名的新子目录。员工只能通过文件工具读写该工作区，命令以该目录为起点。本批不会导入父目录中已有的其他文件。
5. 文件写入沿用 SHA256 条件版本校验。每次终端调用仍等待用户批准，批准绑定运行、员工、工具、完整命令参数和工作区版本，一次批准只能领取一个本机操作。
6. 桌面端回传真实文件内容、SHA256、退出码和输出；后端保存交付物镜像，执行文件合同核验、独立审查与后续交接。运行详情展示设备位置与本机操作回执。

## 权限和边界

设备密钥由桌面主进程生成，用系统加密存储保存在用户配置目录；后端只保存密钥哈希。远程网页没有本机执行或连接配置 IPC。目录选择、启停仅接受本地设置页的主 Frame，远程子页面不能提交目录授权。设备与后端通信使用 HTTPS，仅本机回环测试允许 HTTP；不跟随设备 API 的重定向。

文件工具拒绝绝对路径、上级路径、Windows 盘符/ADS、保留设备名、链接目录、符号链接和硬链接；重查所选父目录身份与文件版本。每次回传最多 128 个文件，单文件 5 MiB、合计 20 MiB；文件读取最多 1 MiB。路径检查无法提供对抗同一系统用户恶意并发替换文件的完整 OS 安全隔离。

本批使用可跨系统传递的文件路径，拒绝 Windows 禁用字符、大小写重名及文件/目录前缀冲突；Windows 的上标数字设备别名也在拒绝范围内。命名依据 [Microsoft 文件与路径规则](https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file)。

本机命令使用当前登录系统用户权限，能够访问工作区外的文件、网络和程序。因此目录文件工具的限制不能视为命令的系统沙箱。Windows 使用非交互 PowerShell，macOS/Linux 使用 `/bin/sh`；模型提示和批准快照记录实际平台。每次命令最多 60 秒、输出最多 1 MiB。

Windows 在调用用户命令前把执行进程加入 kill-on-close Job Object，退出或取消时清理普通后代进程；macOS/Linux 使用独立进程组。进程清理用于结束普通命令和后台子进程，不保证阻止蓄意脱离进程归属的外部系统服务或所有系统调用。Windows 机制依据 [Microsoft Job Objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects)。

## 取消、断线和恢复

桌面端每秒轮询设备任务并上报当前操作。后端在领取、确认开始和接收结果时重新核验运行租约、批准方案、员工权限和设备授权；运行取消、租约失效、停用或断线会停止在途命令。关闭桌面应用同样先取消并等待执行组件结束。

操作开始前持久保存领取记录；真正执行前须收到服务端的开始确认。完成后先持久保存回执，再上传。回执上传失败或桌面进程重启时只补交原回执，已有记录的操作不会自动重新执行。相同回执可重复提交，不同回执和重复开始被拒绝。

已经开始但未取得确定结果的写入或命令保留“结果未知”。命令已经修改文件而回传超过限制，也属于需要核对的修改。迟到回执保留在操作详情，不能替代后继运行或自动恢复任务；用户先检查本机目录，再按现有 C3 核对流程决定重试。

恢复创建新的 Run 和新的本机子目录，导入后端保存的已批准检查点镜像。尚未成功回传的本机修改不会自动成为恢复检查点。预算、调用次数、文件版本、独立验收和恢复准入继续使用已有规则。

停用设备不会删除用户目录中的文件。更换目录、能力或重新启用会生成新的设备与授权身份，旧方案不能静默改绑。业务备份不转移本机设备密钥或本机原始目录；恢复备份会清除设备注册，需在桌面端重新启用并重新批准本机项目。

## 验证

- `npm test --prefix apps/desktop`：真实临时目录与原生命令验证路径、版本、能力、回传失败分类、普通后台子进程清理及断线回执不重放。
- `npm run test:integration`：PGlite、真实 API/队列/DSH，固定模型协议服务。本机场景使用真实设备组件、文件与原生命令；覆盖逐次审批、实际交接和费用归属、凭证/领取令牌拒绝、重复开始与回执、撤权、取消与重连。其他场景仍使用 Docker 执行替身。
- 核心 CI 在 Windows/macOS/Linux 验证上述行为，另以真实 PostgreSQL/Docker 作业验收现有服务端路径和事务锁。
- `node apps/desktop/local.smoke.cjs`：真实 Electron、系统加密存储与原生命令；HTTP 协调端和目录选择对话框使用固定夹具。覆盖本地设置页授权、凭证加密、实际文件/命令、退出取消、重启不重放和停用。Windows 工作流同时运行打包版与安装版，macOS 运行本地 Electron 构建。

真实模型业务质量、线上部署、浏览器/桌面应用控制、正式签名和自动升级留待后续，不由以上固定夹具验证代替。
