# 员工上下文管理

2026-10-01，C1 基于独立员工 Host 接入 DSH 的公开 TokenMeter、BasicCompactionEngine 和 ToolResultPruner；未修改安装依赖。

## 配置与行为

模型配置新增可选的“上下文容量（Token）”。填写中转站实际支持的输入与输出总容量，不按模型名称猜测。该字段进入批准快照和配置指纹；修改后原有能力测试和项目批准不能继续使用。

项目策略可选择：

| 模式 | 行为 |
|---|---|
| 自动摘要与工具结果缩减（默认） | 步骤之间先缩减大型工具结果；配置模型容量时，根据员工自己的历史和当前路由测量压力，必要时调用同一批准模型生成摘要 |
| 仅缩减工具结果 | 保留工具结果来源、头尾正文及可保留的结构化元数据，不调用摘要模型 |
| 仅限制请求大小 | 保留原有请求字节上限保护，不安装摘要和工具缩减服务 |

未配置模型容量时，默认模式仅使用工具缩减和字节上限保护，并在运行时间线注明原因。每个员工（包括经理）有自己的测量、摘要、工具缩减和取消状态；模型容量、工具定义、系统提示及历史共同影响压力。Token 测量使用 DSH 估算及供应商用量校准，不是所有模型的精确 tokenizer。

压力门限最多为声明容量的 70%，并受项目与路由字节上限的保守估算约束。近期历史保留量和摘要输出上限也按路由调整。每个步骤最多尝试一次摘要，不因上下文错误盲目重复模型调用。过小的容量或字节上限可能无法容纳系统提示、工具定义和最近消息；此时需要调整配置或减少提示内容，不能靠丢弃任务要求保证继续执行。

## 任务、证据和来源

员工的每次系统提示固定批准需求、岗位、允许工具和当前任务合同。当前任务编号、attempt 凭证、状态与进度由宿主任务状态读取，验收标准、文件范围、输入、输出和预算来自批准快照。摘要不能扩大权限或成为文件、命令的验收证据；现有交接门禁继续核验实际文件与命令。

工具缩减优先处理 JSON 内的正文、输出或片段，保留能够装入上限的路径、SHA256、返回状态和引用信息。无法保留完整结构时使用正文头尾缩减；完整工具结果仍在原始会话记录中。缩减事件关联原始 source seq，摘要记录关联替换范围、原始输出和调用用量。会话恢复会重建替换后的可见历史，同时保留被替换的原始记录。

摘要请求读取它所替换的完整历史前缀，不能先删除来源再生成摘要。超过字节上限的摘要输入在发送前被拒绝。普通执行请求的字节保护保留最近有效摘要、系统提示、最新用户消息及完整工具往返；保护内容仍超限时停止该请求。

空摘要、无法缩小历史的摘要及取消中的摘要不会替换来源。摘要成功后若整体仍超过压力门限，该步骤会报告错误，已经提交的有效摘要和原始历史继续保留。工具与摘要的步骤错误由原生调度器和现有产品失败策略处理；模型传输或预算错误遵守产品 Run 的统一停止策略。独立 Host 不代表进程故障隔离。

## 费用与查看

摘要经过原有模型并发门禁、项目/任务调用次数、项目/任务费用上限、部门日额度、授权复核和调用预留。账单用途为“上下文摘要”，关联员工、会话、任务、attempt 和请求；经理协调请求计入项目。已发送但最终不能替换历史的摘要调用也按实际回执计费。

运行时间线展示工具缩减、摘要来源与用量、整理失败和未配置容量事件。展开实际模型请求可确认用途及发送内容；原始会话记录与导出继续包含完整证据。长运行采用分页读取，不能把第一页当作全部档案。

## 验证边界

实际 DSH 测试覆盖独立状态、员工历史隔离、摘要后继续执行、持久恢复、结构化工具证据、调用次数拒绝、取消、缩减不足拒绝、未知容量、完整摘要输入和有效摘要的字节保护。模拟 API 流程覆盖长历史触发真实 HTTP 摘要请求、成功及失败摘要计费、批准合同保留、命令审批、文件交接与独立审查。

测试使用本地模型协议替身，不产生真实中转模型费用。真实模型的摘要质量、长任务完成质量及远程部署尚未验收。跨平台与真实 PostgreSQL/Docker 的结果以核心 CI 为准。
