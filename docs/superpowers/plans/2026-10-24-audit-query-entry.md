# 审计查询入口：D2 Task 7 首片

继续已批准的企业可观测性计划。先复用现有不可变 `human_audit_events`、`audit-outbox.ts` 的严格摘要解析、A2 当前身份检查以及网页 `api()`，不新增日志服务、模型调用或外部上传。

范围：管理员/本机所有者通过设置页手动展开并查询审计摘要；使用真实 HTTP 与隔离数据库验证。当前普通成员与审计员的网页会话尚未接入相应业务视图，本片不扩大其访问。成员运行别名、专用审计员入口、导出、OTLP 与完整备份继续保留为未完成项，不将本片称为 D2 全部完成。

1. 先写接口失败测试：未登录/设备/成员/审计员拒绝；数据库当前身份和 epoch 失效拒绝；规范历史摘要可查询，无投影仍能查询；原始正文、凭据、任意 changes 不回传。
2. 实现 `GET /api/audit/events`，只查询原审计表。过滤 runId、correlationId、outcome、after、before；默认七天、最长三十天；每页默认 50/最大 100；参数严格校验，游标绑定过滤条件和主体，保留 PostgreSQL 微秒顺序。旧或无效记录显示摘要不可用，不推测身份或隐去整行。
3. 读取和 `audit.read` 记录同一短事务；成功响应在提交后返回。当前身份锁贯穿查询；撤权后的下一页拒绝。数据库原错误不泄漏；未知事务结果丢弃连接，不自动重试。
4. 页面仅展开时读取，一次一个请求、手动刷新、分页；关闭/退出/失败清空已有内容，丢弃迟到响应。使用原样式，不新增图表依赖。
5. 独立 API/前端状态测试、原摘要投影回归、路由目录和类型/构建检查；共享 app/catalog 接线等待 A2 作者交接。保存测试输出、独立复核与未验证项，不调用 Computer Use。

实现所有权：父级新 `observability-router.ts`、`audit-query.ts`、`AuditHistory.tsx` 与对应测试；`audit-outbox.ts` 仅导出复用现有摘要解析的入口，`SettingsCenter.tsx` 仅挂载。A2 正在编辑 app/catalog/api-access，不并发修改。
