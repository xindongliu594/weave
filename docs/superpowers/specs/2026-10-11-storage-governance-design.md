# 文件与数据治理：第一批

用户已批准聊天中的四批方案并要求开始，本批交付容量统计、清理预览、明确确认及恢复保护。继续使用 React/Express、DSH 运行档案、文件哈希和当前数据库，不增加依赖。

## 本批规则

- 只读盘点运行档案、本机数据与工作区。可配置 `WEIWU_STORAGE_BASE` 盘点固定部署目录；该目录只读，不向网页提供任意路径扫描能力。
- 统计逻辑字节、文件数、符号链接和读取失败；不跟随链接，不把不完整扫描报告为完整容量。按运行展示交付、会话、原始日志及其他占用。
- 保留 64 MiB 单运行、1 GiB 运行档案门禁。补充文件系统可用空间低于 256 MiB 时的新增运行/模型/命令审批门禁，不删除证据。该门禁不是容器硬磁盘配额。
- 清理只支持当前本机执行器工作区内的普通文件副本：运行已 completed、没有待执行或结果未知操作、完整交付档案中存在完全相同的文件。保留所有失败、停止、活动、未知和未登记现场。OpenShell 容器和旧发布仅盘点，不删除。
- 检查 run 快照（最大 8 MiB）、事件日志（最大 64 MiB）、完整性和正常完成，复用现有未知操作识别；文件及祖先不允许链接，文件不允许硬链接；不提供扩展名/年龄猜测删除。
- 预览持久化、30 分钟有效；显式确认当前预览。执行前重新核对数据库状态、路径、内容和文件身份；先检查整批再删除单个普通文件，不递归删除目录。
- 清理与运行/操作表使用排他业务门禁。记录 started/completed/partial/interrupted 结果；服务中断后仅核对现状，不自动续删或重放。原档案始终可用于恢复已清理的副本。
- 清理记录随在线及离线备份保留，旧备份缺少新表时可恢复为空表。恢复实验使用隔离目录。
- 相同有效清单复用预览；去重、容量检查、插入在同一事务锁下完成；清理元数据最多 1000 条 / 16 MiB（含删除及核对结果预留），超过后停止新增预览，保留已有记录。工作区增量枚举前 1000 条，按候选投影查询；单工作区 512 条目，清单最多 4096 文件。最近 50 次运行详情有界展示，总档案扫描最多 100000 条目。
- 设置页面提供占用、限额/失败原因、清理清单、确认、记录及中断核对。默认无自动删除，不调用模型。

## 验收

用真实临时文件和隔离数据库验证正常清理、引用/状态保护、文件变化/链接拒绝、重复确认、中断核对、重启后预览与记录、隔离备份恢复及交付哈希。JJ 只读盘点、部署后核对历史交付和费用不变，浏览器验证设置页面。没有磁盘硬配额和多小时耐久验收结论。
