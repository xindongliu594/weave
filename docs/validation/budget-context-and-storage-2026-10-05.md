## 员工调用上下文

每位员工有自己的 Host 和会话。员工不会自动继承其他员工的完整对话；通过团队任务、消息、文件交接和工具读取获得所需资料。发送给模型的内容包括岗位与批准的需求、当前任务合同、权限内的工具定义、保留的本员工会话与工具结果，以及必要的固定版本文件或知识检索证据。

模型请求按会话重新构造。资料写入磁盘不等于模型之后无需输入就能记住；文件或知识内容仍在活跃上下文中时，后续请求会再次发送，并可能重复计算输入费用。不能保证代理始终给出缓存优惠。

`employee-context.mjs` 对长工具结果缩减，完整文件及必要证据受保护；摘要需要模型上下文容量配置。摘要也经过同一模型、权限及预算边界。当前受预算保护的内容不能为了继续调用而丢弃独有验收证据。
