# 已验收任务终态停止：API 基础

本批 API 基础已通过 104 项匹配回归、类型检查及独立复审。它为宿主提供可信的终态停止与原请求核对接口；运行时、网页接线、连续项目及物理 JJ 验收另行记录。任务 profile 仍关闭，不能据此宣称企业基础能力整体完成。

终态停止先核对全部当前批准任务的独立验收、持久检查点和原 HTTP/SQL 操作提交链，再沿既有设备维护队列执行。每批最多两个新的停止，使用同一个 120 秒截止时间；首次结果不明就保留现场。历史已退休或被返工替代的任务，不借用新任务的检查点取得新的停止权。

本次复审修复了两个实际边界：

- SQL 服务端超时不能覆盖客户端迟迟收不到回包。现在复用已安装 `pg` 的 `query_timeout`，共享取消时丢弃原连接，并阻止其后续回调获得派发权。测试暂停真实 pg socket 收包，分别覆盖 BEGIN、SET、查询、派发 COMMIT 和 ROLLBACK 的取消及截止时间。
- SQL 已记为停止，也不能跳过当前本地绑定检查。再次核对会经过冻结的 provider 查询原请求 ID；替换原授权目录 inode 会拒绝，且不会再次发送停止。
