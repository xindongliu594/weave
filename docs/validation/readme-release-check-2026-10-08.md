## 本轮发现与修复

旧产品测试夹具只从 system 消息读取任务快照。当前 DSH 使用最新 user runtime-context 快照，摘要后旧任务分派文本会移除；旧夹具因此丢失 task/attempt，错误返回结束文本。现已读取最新快照，保留旧格式兼容，并拒绝用旧 attempt 替代无效的新快照。

返修合同保留原任务 subject，夹具现从批准的 `kind/reworkRound` 识别返修和复验。上下文与恢复断言同步检查当前快照；固定摘要改为有效短摘要。

模拟模型原声明的 8K 容量使软压缩阈值低于当前工具及批准上下文的固定基线，导致重复压缩或先耗尽测试调用数。临时模拟模型声明调整为 16K，容量断言共用常量；全部真实费用额度、测试调用上限、权限和生产逻辑保持原值。摘要场景实际产生摘要并验证费用归属，没有关闭压缩或放宽通过条件。

初始超时、过渡失败及完整原日志仍保留在本机；API 43 项公开输出是初始组合日志中四个成功文件的精确前缀，原日志 SHA-256 为 `e95429ef1d754eef092f98f9792a8d3869594f1b6664306184d8aa397eba2b0c`。最终产品全套输出中那条旧断言失败也如实保留。

产品全套公开日志仅去掉两行空白行末的四个空格，未改变结果或错误内容。规范化前的原字节另存本机，SHA-256 为 `403fa15f1a75ae02c94d4b0c5225e74389e3a6ec626c530cca26b16662d649f1`。
