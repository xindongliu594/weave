# sum.mjs — 整数加法模块

Node ESM 模块，导出 `sum(a, b)`，仅支持整数相加并返回结果。

## 用法

```js
import { sum } from './sum.mjs';

sum(2, 3);    // 5
sum(-2, -3);  // -5
sum(0, 7);    // 7
```

非整数输入（如 `1.5`）抛出 `TypeError`。

## 运行测试步骤

要求：Node.js 18 或更高版本（无需安装任何依赖，不联网）。

```sh
# 1. 进入本目录
cd <项目目录>

# 2. 运行冒烟测试
```
