已验证：

- 规划请求在原有一次请求中附带七类有界目录、冻结引用和绑定示例；不增加请求、不扩权限。
- 本地模型桩提供的七类合法候选均可形成 API 预览、显式确认和保存版本；错误模板、hash、绑定返回明确草案问题。尚未验证真实 AI 能自动选对模式或生成合格方案。

- React 静态渲染验证了中文名称、版本、选择依据及“离线校验，待真实验收”的显示，旧显示保留；本轮未做浏览器端到端验收。高级草案保存保留原方案其余字段。
- 档案读取及资源恢复原样保留冻结元数据，包括当前目录不认识的历史 hash，不重新选模板。
- AgentTeams 0.1.20 公共 profiles 可以创建、暂存和批准；seed 不支持结构化文件合同，会拒绝 inputs。公共 create_task 可通过 description 保留宿主文件合同，宿主仍负责校验。探针使用公共事件阻止调度执行，推理调用 0。
