# 退款验收用例（整数分）

约定：金额单位一律为「分」，仅接受整数（JS 安全整数 ±9007199254740991）。小计＝Σ明细；退款＝Σ退款行且不超过小计。任何非整数分或超安全整数输入必须报错，禁止四舍五入、取整或截断。

## 检查表

**A. 正数**
- A1 输入：小计 1200，退款 500 → 预期：结余 700（正数正常扣减）。
- A2 输入：小计 1，退款 1 → 预期：结余 0（最小正数全额退，不为负）。

**B. 负数**
- B1 输入：明细 -300、-200 → 预期：小计 -500，报「小计为负」错误。
- B2 输入：小计 1000，退款 1200 → 预期：报「退款超小计」错误，不出现负结余。

**C. 零**
- C1 输入：小计 1000，退款 0 → 预期：结余 1000，不产生零元退款记录。
- C2 输入：小计 0，退款 0 → 预期：结余 0，合法且不报错。

**D. 连续变动**
- D1 输入：小计 900，依次退款 200、0、300、400 → 预期：结余 700、700、400、0，每步校验。
- D2 输入：接 D1 再退 1 → 预期：报「退款超小计」错误，结余保持 0 不变。
- D3 输入：明细 100、200 加入后撤销 -200 → 预期：小计 300、300、100，与顺序无关。

**E. 非整数**
- E1 输入：退款 10.5 → 预期：报「必须为整数分」错误，不截断为 10 或 11。
- E2 输入：小计 0.1+0.2 → 预期：报错（0.30000000000000004 非整数），不取整为 0 或 1。
- E3 输入：退款 "500"（字符串）/ NaN → 预期：类型报错，不隐式转换。

**F. 安全整数边界**
- F1 输入：小计 9007199254740991（MAX_SAFE_INTEGER），退款 1 → 预期：结余 9007199254740990，精确。
- F2 输入：小计 9007199254740991，退款 9007199254740991 → 预期：结余 0，精确。
- F3 输入：小计 9007199254740992（超 MAX_SAFE_INTEGER）→ 预期：报「超出安全整数」错误，不截断、不精度丢失。
- F4 输入：9007199254740991 + 1 作为小计 → 预期：加法溢出即报错，不回绕为负数。
- F5 输入：-9007199254740992 → 预期：超出安全整数下界，报错。

## 通过准则

A–F 六类全部执行且每条输入输出与预期一致；凡非整数分、超安全整数输入，均须返回明确错误（含错误码/消息），不得静默截断、取整或精度丢失。任一条不符即整体不通过。
