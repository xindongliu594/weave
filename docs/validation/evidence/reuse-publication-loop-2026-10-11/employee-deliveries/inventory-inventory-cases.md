# 整数库存入出库变动合计 · 验收用例检查表

固定语义：单条变动为正=入库，为负=出库；合计=各条变动求和；库存与变动均为整数。预期结果由本表按上述语义手工推算，无测试代码。

## 一、用例表

| 编号 | 类别 | 输入（变动序列） | 预期结果 |
|---|---|---|---|
| C1 | 正库存调整 | `+5, +3` | 合计 `+8`；两笔均为入库，库存净增 8 |
| C2 | 负库存调整 | `-5, -3` | 合计 `-8`；两笔均为出库，库存净减 8 |
| C3 | 零变化 | `0, 0` | 合计 `0`；库存不变，且不视为入库或出库业务 |
| C4 | 零变化 | `+7, -7` | 合计 `0`；一入一出相抵，库存不变，但两笔业务均须留痕 |
| C5 | 组合变动 | `+10, -3, +4, -1` | 合计 `+10`；入库共 14、出库共 4，净增 10 |
| C6 | 组合变动 | `-10, +6, -1` | 合计 `-5`；入库 6、出库 11，净减 5 |
| C7 | 非整数拒绝 | `+2.5` | 拒绝；不产生合计、不改变库存，并给出「非整数输入」错误 |
| C8 | 非整数拒绝 | `+3, -1.2` | 整串拒绝；不做部分累加，合计不可得，库存保持原值 |
| C9 | 非整数拒绝 | `1/2`、`"5"` | 均拒绝；分数与字符串不是整数域取值 |
| C10 | 整数边界 | `+2147483647, +1` | 拒绝或按约定的整数上限溢出报错；不得回绕为负库存 |
| C11 | 整数边界 | `-2147483648, -1` | 拒绝或按约定的整数下限溢出报错；不得回绕为正库存 |
| C12 | 整数边界 | `+2147483647, -2147483647` | 合计 `0`；上下界可精确相抵，库存不变 |

## 二、库存业务约束与通用加法方法的差异

已按获授权整数加法方法核对：先确认整数输入域，再检查正数、负数、零三类求和，并明确拒绝非整数；该方法只适用于整数加法，不得假设其对任意实数成立。在此基础上，库存业务另有更严约束：

1. **符号即业务**：通用加法只关心数值，`+5` 与 `-5` 皆为合法加数；库存中符号决定入库或出库，方向错即业务错。
2. **零值语义**：通用加法中 `0` 是合法加数即可；库存中零变化不等于入库或出库，C3、C4 须按「无业务发生/仅互相抵消」核对。
3. **非整数拒绝面更广**：通用加法只需拒绝小数；库存还须拒绝分数、字符串、缺失值等非整数表示（C7–C9），且拒绝须整串生效，不得部分累加。
4. **边界后果不同**：通用加法溢出可能仅数值出错；库存溢出可能导致库存非负约束被破坏，故 C10、C11 要求拒绝或明确报错，禁止回绕。
5. **业务前置校验**：通用加法可直接求和；库存须先逐笔校验整数性与符号合法性，再求和。
