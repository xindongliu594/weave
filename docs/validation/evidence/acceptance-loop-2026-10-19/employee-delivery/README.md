# 温度换算 CLI（cli.mjs）

一个无第三方依赖的 Node.js 命令行小工具：把摄氏度（C）换算为华氏度（F），公式为 `F = C * 9 / 5 + 32`。

## 运行方式

需要本机已安装 Node.js（建议 Node 18 及以上）。

```sh
node cli.mjs 25
node cli.mjs -40
node cli.mjs 36.6
```

## 参数规则

- 需要且只需要 **一个** 位置参数。
- 参数必须是数字，**允许负数**（如 `-40`）和**小数**（如 `36.6`、`-0.5`）；也接受 `+12`、`.5`、科学计数法（如 `1e2`）等 JavaScript 风格数字写法。
- 不接受空字符串、`abc`、`NaN`、`Infinity` 等非数字内容。

## 输出格式

成功时向 **stdout** 输出一行 JSON，结构固定为：

```json
{"celsius":25,"fahrenheit":77}
```

- `celsius`：输入的摄氏温度（数值）。
- `fahrenheit`：换算后的华氏温度（数值，按 `C*9/5+32` 计算，未做四舍五入）。

## 错误行为

以下情况会向 **stderr** 输出中文提示（含用法说明），并 **以非零退出码（1）结束**，stdout 不输出 JSON：

- **缺失参数**：`node cli.mjs`
- **非数字参数**：`node cli.mjs abc`
- **多个参数**：`node cli.mjs 1 2`

示例：

```text
错误：缺少参数，需要且仅需要一个数字型的摄氏度参数。
用法: node cli.mjs <摄氏度数字>（允许负数与小数，例如 25、-40、36.6）
```

## 已知限制

- 只支持摄氏 -> 华氏单向换算；反方向需另行实现。
- 只处理单个标量输入，不支持批量、文件或交互式输入。
- 输出为原始浮点结果，可能出现 `-17.77777777777778` 这类长小数，未做精度或格式化处理；浮点误差不做修正。
- 不校验物理合理性（数值大小不受限），不使用绝对零度等边界约束。
- 参数解析为自定义规则：前导零、`1.`、`.5`、指数写法均被接受；带千分位分隔符（`1,000`）或带单位（`25C`）的输入会被拒绝。
- 仅适用于 Node.js 运行时，不提供浏览器或其它语言版本。
