## 修复的问题

1. 原目录只有列举和启停，缺少网页安装入口。现可通过安装任务接入同类工具插件，不必逐插件修改 Host、员工运行器或 worker。
2. 安装构建直接写最终版本目录会留下半成品。改为临时构建、验证后原子发布；重复字节校验后复用，不覆盖历史版本。
3. 真实计算器构建暴露元数据文件重复以 `wx` 写入的 `EEXIST`。已修正并用同一原版包重跑成功，发布目录仅保留三项正式安装文件。
4. 可移植校验同步完成时，网页只等待轮询而不刷新目录。现提交完成后立即刷新，并记住本标签页安装任务。
5. 新安装路由纳入精确 admin 门禁，沿用现有 CSRF/幂等；演示模式拒绝安装。配置拒绝命令、目录、版本范围、敏感配置和未声明文件字段。
6. 独立审查指出 npm 包入口或相对导入可越出来源目录。现对入口和 esbuild 模块读取实施路径边界，越界拒绝的两个回归已通过；原版计算器仍生成相同版本字节。
7. 暂时读取失败不再删除安装任务编号；新文件解析失败先清除旧的可移植选择，避免误装上一个文件。
8. npm 下载增加 Node 权限边界、私有配置与缓存、安装期间空间采样，避免继承用户 npm 凭据。工具探测改用异步子进程，避免阻塞安装状态查询。
9. 仅清理有归属记录、子进程已退出的暂存目录。进程仍存活或启动窗口的状态无法确认时保留，不因服务重启盲目重放或删除。
10. 边界加固后的 Office 实测暴露裸依赖被仓库祖先目录同名包遮蔽的问题。现只有允许目录的依赖能被打包，必要时回退固定 DSH 依赖树；未把整个仓库依赖目录放开。最终 Office 原版安装通过，计算器重建仍为相同版本编号。

独立审查先提出构建路径 P1 与网页状态 P2，修复后聚焦复审均关闭，当前切片无剩余 P1/P2 阻断项。审查不扩大本报告的验证范围。

## 复核位置

本地私有记录保存在 `.superpowers/sdd/2026-10-23-plugin-plug-and-play/`，包含原代码快照、原版来源摘要、构建包、可移植 JSON、独立测试数据库和组件结果。它们不包含项目 API Key 或生产数据库连接串。运行结果及原版源摘要另保存到本报告同名 evidence 目录。

主要复核命令：

```powershell
node --import tsx --test tests/native-plugin-install.test.ts tests/native-capability-store.test.ts tests/native-capabilities.test.mjs tests/native-plugin-worker.test.mjs tests/api-access.test.ts tests/request-origin.test.ts

node scripts/validation/native-plugin-calculator-smoke.mjs <计算器安装版本目录> <新的证据输出目录>
npm run build
```

普通工作区沙箱曾阻止 esbuild 读取父目录，后在允许的本机构建上下文通过；不能把这个工具环境错误当作产品编译错误。浏览器来源审批有一次超时、重试后成功，文件选择也出现较长审批等待；原始 UI 检查与启用状态截图保留在本次会话。

故意让安装状态接口返回一次 503 后，实际网页保留原任务，并显示“暂时无法读取”和“重新读取安装状态”。点击重试按钮的补验连续两次遇到浏览器自动审批超时，未获得决定；因此只记录状态保留与按钮显示通过，不宣称实际点击补验通过。正常安装、启用、刷新与停用的浏览器检查已有通过记录。

## 未验证和限制

- **未验证**：本轮新安装版本的 JJ OpenShell 真机执行、付费模型自主选择插件及独立 QA/经理验收；既有 Office 的真实证据仍见[原报告](native-capability-integration-2026-10-18.md)，不能冒充本轮重验。
- **已发布**：JJ 已切换到本轮版本，服务及新安装接口检查通过；Windows 浏览器经隧道的最终可用性单列在[部署记录](plugin-install-deployment-jj-2026-10-23.md)，不以服务检查代替浏览器验收。
- **范围限制**：工具插件兼容模式、接入 JSON 与文件权限元数据；尚无市场搜索、原生插件页面直嵌、常驻服务模式或私有 registry 登录。上传和空间限额见[使用说明](../plugin-installation.md)。
- **清理边界**：安装进程被强制终止后，重启将任务标为中断；只回收归属与退出状态均能证明的暂存目录，其余保留并提示管理员检查。在创建目录与写入归属记录之间发生硬崩溃，仍可能留下无法自动认领的目录。空间限制是应用层采样，不保证峰值硬上限。
- **工具补验受阻**：故障后“重新读取安装状态”的实际按钮点击被浏览器自动审批连续两次超时阻塞；未把超时表述为安全拒绝或产品测试通过。

本轮仅验证插件接入切片，整体企业级 MVP 与旧恢复写入加固仍有独立未完成项。
