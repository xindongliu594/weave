## 私有热部署准备及边界

私有脚本保存在工作区 `.data/research`，不属于公开源码提交范围。脚本核对基线/派生源码清单及冻结 payload，拒绝未知修改和符号链接越界。先备份原源码、派生清单与完整网页包；本机 UI 回归、类型检查与唯一 staging 构建成功后，再发布新资源，最后原子替换首页。旧哈希资源保留，避免旧标签页请求 404；已有 API 与服务不重启。

执行时必须处于原运行终态或稳定待审批点，且已知账目没有进行中/未知费用。部署前、发布前及发布后，读取本地健康、原 Run/快照、DAG、项目账目、调用、审批、交付文件，并验证服务/API PID 及进程启动身份不变；原快照字节与事件日志字节前缀保留。只读轮询可以追加事件，不要求事件总数相等。原运行方案与最新项目方案可不同，部署不代替恢复或批准。

费用、任务或审批发生变化时阻止部署；已发布后发现变化或检查失败，只恢复此次 UI 源码/网页包/派生清单，保留检查日志与备份，不回滚业务数据、审批或调用。脚本未调用真实模型、未操作生产数据库、未安装依赖、未执行 SSH。
