## 发现并修复的问题

`backup.ts` 原本对档案设置 30MiB 门禁，同时允许整体解密明文达到 50MiB。实际两次运行的档案为 `35,505,523` 字节、完整投影明文 `47,521,694` 字节，低于 50MiB，却被前一个门禁拒绝。已改为统一 `ONLINE_BACKUP_LIMIT_BYTES=50*1024*1024`；**整体 JSON（含 base64 文件）仍不能超过 50MiB**，路径校验、加密、事务、恢复前档案保留及回滚逻辑保留。

专用 `tests/backup-size.test.ts` 独立建立工作区数据库和目录，实际 API 回归 2 / 2：31MiB 文件对应 `43,345,512` 字节明文，可导出、恢复、再导出；38MiB 文件对应 `53,132,288` 字节明文，导出与恢复均被拒绝，原目标表、费用和文件保持一致，恢复 staging 未建立。原有扩展备份测试 3 / 3、类型检查和脚本语法检查均通过。

本地投影 fixture 还发现 Vault frontmatter 会改变引用行号。脚本依据只读 citation API 验证并固定已引用版本的原行号偏移；不会用当前正文行号替代历史引用。资料从版本一改为版本二后，恢复及重开仍读取被批准的版本一。授权、私有资料隔离及运行恢复引用的完整本地证据另见 `docs/mvp-data-progress.md` / `docs/test-evidence/mvp-data-2026-10-02.json`，不将这些合成资料当成真实 Todo 员工验收。

## 未验证与边界

- **凭据跨环境迁移未验证**。原始 Key、主密钥、设备凭据与本机目录授权未读、未复制；目标没有 `credential.key`。之前直接复制主密钥被自动审批拒绝，本次使用已获准的不含凭据投影路径。目标仅用于核验，不作为可直接继续调用模型的正式环境。
- **主环境全量在线导出未执行**。全环境超过 50MiB 整体明文时仍无法在线导出；本次只恢复选定项目的关键业务数据，不声称全部原环境都能在线恢复。
- 投影包含指定运行、该项目费用关联运行及恢复父链；没有费用关联的孤立运行在范围外。数据库租约、取消标记、错误列和运行尝试序号由档案重建，未复制原数据库内部运行控制行。
- 已结算费用与调用事件保留；模型预留租约/原始核对历史、经理聊天、自动化、MCP、导入工作文件扩展表、设备授权均不在真实投影范围内。
- 此真实 Todo 项目没有知识文档和引用，知识恢复证据来自少量隔离测试资料。保留引用版本、内容、SHA 与已引用版本的原行号；未引用版本采用正文相对行号。原始 Vault 文件、实时路径和向量索引未迁移，历史来源元数据仍保留。
- 单个不可变档案经过采集前后复核，但多条只读 API 不等同于整个源数据库事务快照。PGlite 单连接验证不覆盖独立 PostgreSQL 后端锁竞争。部门版本内容核对，当前版本的数据库触发器时间戳不作逐字节一致断言。
