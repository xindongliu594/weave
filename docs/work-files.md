# 项目素材与办公文件最小版

“项目素材”支持选择本机文件或一个目录，通过浏览器上传独立快照。服务端不会按客户端提供的路径读取宿主机，也不会修改原目录。快照保存原始文件、相对路径、SHA256 和提取正文，重启后保留；下载返回原始文件。

## 使用流程

1. 在“项目素材”选择文件或目录，检查将导入的文件，再保存快照。常见凭证、依赖及不支持的二进制文件会在选择时提示排除，服务端会再次校验。
2. 在项目方案的“选用导入素材”中，勾选具体文件及授权员工。员工需有知识检索权限；没有勾选的文件不会自动加入项目知识。
3. 默认只提供参考正文。勾选“复制文本文件到独立运行工作区”后，选中的代码 / CSV 副本保留相对目录结构；需授权该项目所有具备文件或终端工具的员工。后续修改作用于 Run 副本，不回写原目录。
4. DOCX / XLSX / PPTX 以提取正文供员工检索。员工先用现有交付工具输出 Markdown / CSV；可在“生成办公文件”粘贴正文或二维 JSON 表格数组，生成 DOCX / XLSX / CSV 并下载。

导入内容是未受信的参考资料，不应当替换用户需求、员工工具权限、预算或执行审批。目录中的脚本不会因为导入而运行；执行仍沿用已有审批。

## 支持范围

| 格式 | 导入 / 读取 | 生成 |
| --- | --- | --- |
| UTF-8 代码、TXT、Markdown、JSON、CSV | 保留原始内容和路径 | 员工现有文本交付工具；页面可生成 CSV |
| DOCX | 正文段落及表格中的文字 | 简单标题、正文段落 |
| XLSX | 工作表文本、共享字符串、保存的公式缓存值 | 单个工作表的文字 / 数值表格 |
| PPTX | 幻灯片中的文字段落 | 暂不支持 |
| PDF、旧版 DOC/XLS/PPT、图片、ZIP | 暂不支持 | 暂不支持 |

此版本不保留图像、页眉页脚、复杂排版、图表、批注和修订，不重算公式，不执行宏，也不会请求文档中的外部链接。XLSX 生成的单元格使用文字值；CSV 以单引号转义可能被表格软件当作公式的内容。

## 限额与隔离

- 单次快照最多 100 个文件，单文件 2 MiB，原始内容合计 8 MiB。
- 单文件提取正文最多 250,000 字符。Office ZIP 最多 1,000 个内部条目，展开合计最多 8 MiB。
- 本次项目资料最多 20 份，每份最多 50,000 字符，合计最多 250,000 字符；计入既有项目资料总额。
- 素材库最多 200 份快照 / 128 MiB 原始内容。最小版快照不可变，不提供原地替换或清理；备份包含快照表。
- 表格生成最多 2,000 行、100 列、20,000 个单元格；每个单元格最多 10,000 字符。
- 路径最多 240 字符，与执行工作区一致；拒绝 `.agent*` 团队保留目录、绝对路径、父目录跳转、Windows 驱动器 / 流路径、保留设备名、重名及文件 / 目录冲突。拒绝 `.git`、`.env*`、`.ssh`、`.aws`、常见 credentials / secret 文件、私钥格式和私钥正文。
- 浏览器上传的是文件字节，不携带可执行的符号链接语义；服务端不接受链接对象或 `.lnk/.url`，Office 内部链接条目也会拒绝。它不扫描用户整块磁盘，也不承诺识别所有业务秘密，请在上传前检查选中文件。
- 所有已选择文本副本在交付前重新核对原始 SHA256；正文也与原始文件重解析结果核对。落盘前先验证全部路径 / SHA，逐级拒绝根目录及父目录中的符号链接 / Windows junction，并以独占创建禁止覆盖已有文件。
- 恢复运行复制父 Run 的当前产物，保留上次修改；不会重新写入原始导入文件。导入项目的父产物目录缺失时明确停止，要求先恢复档案。

## 接入点

`migrateWorkFiles(pool)` 创建 `work_file_snapshots` 表；`workFilesRouter()` 挂载在 `/api`。`/api/work-files` JSON 请求体需要在全局 2 MiB parser 前配置 12 MiB 限额（base64 会增加传输大小）。

- `GET /api/work-files`：快照摘要列表。
- `POST /api/work-files`：`{name,files:[{path,base64,kind?:"file"}]}`，原子校验后保存。
- `GET /api/work-files/:id`：正文与文件元数据，不返回 base64。
- `GET /api/work-files/:id/files/:index/download`：原始文件下载，强制 attachment / nosniff。
- `POST /api/work-files/generate`：`{format,name,title?,text?,rows?}`，生成并保存可下载快照。

`selectedWorkFileInputs([{snapshotId,paths,agentIds,mode?}], db?)` 返回与 `attachRunInputs` 兼容的正文资料；`selectedWorkFileCopies(...)` 仅返回 `mode:"workspace"` 的文本 / CSV 副本，不写磁盘。调用者验证员工、工具授权和运行工作区，再冻结在批准快照内。`readWorkFileSnapshot(id, db?)` 供后台授权后读取原始快照；不能直接暴露给模型作任意素材枚举。

Office 处理位于 `services/agent-runtime/office-files.mjs`，使用已有 `adm-zip 0.6.1`，不依赖本机 Office 或 Python。生成器仅操作内存字节，文件写入不能绕开现有 artifact handoff。

## 验证
