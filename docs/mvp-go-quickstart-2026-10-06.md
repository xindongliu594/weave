## 启动

当前服务已经运行时，直接打开网页即可。需要重启时先在原启动窗口按 `Ctrl+C`，等待关闭；不要删除锁文件或修改数据库。

本轮 API 使用并验证了 Node 24.19.0。当前电脑可以在代码目录打开 PowerShell，使用已安装的运行时启动：

```powershell
Set-Location 'C:\Users\JJ\.codex\worktrees\f57c\agent_department'
& 'C:\Users\JJ\.cache\codex-runtimes\codex-primary-runtime\dependencies\node\bin\node.exe' scripts/local.mjs --production --data-dir=C:\Users\JJ\Desktop\la\agent_department\.data\local
```

保留该窗口，结束时按 `Ctrl+C`。一般安装环境可使用 `start-local-production.cmd "--data-dir=你的绝对数据目录"`；它先构建网页再启动。首次安装需在仓库目录运行 `npm ci` 和 `npm --prefix services/agent-runtime ci`，根目录与员工运行器各有独立锁文件。生产启动使用现有 `dist/web`；源码修改后运行 `npm run build`。

1. 在“模型目录”使用已保存的 **Go · DeepSeek V4.1 Flash**。中转站前缀为 `https://opencode.ai/zen/go/v1`，模型为 `deepseek-v4.1-flash`，协议为 Chat Completions，显式关闭 thinking。Key 在网页保存。本轮模型已通过真实文本和两轮工具测试，查看结果不需要再次发付费测试。
2. 到“需求组建”，在输入框下明确选择“负责组建的模型 → Go · DeepSeek V4.1 Flash”。网页会保留之前选过的模型，切换中转站不会自动改旧会话。展开“组建设置”，在“员工与后续规划可用模型”中选择本次愿意使用的模型；只用 Go 时取消之前的 Astra、Luna、Sol。指定自己的项目总费用上限，AI 在该上限内分配任务预算和调用次数。若有结果不明的旧请求，先继续获取原回复，或保留未知费用后开始新需求；不要修改原请求正文来重发同一请求编号。
3. 输入需求，持续补充和修改。没有可用方案、生成失败、待确认方案和已保存方案会分开显示。需求对话和生成候选会调用模型并记费；确认仅保存正式方案，批准才开始员工执行。确认各岗位、模型、工具、任务依赖和验收标准后，点击“确认组建团队”。确认之前不会保存正式部门、员工或项目。
4. 到“项目与方案”查看已保存方案与校验；修改候选时先生成、检查，再确认保存。点击“批准并运行”后开始真实模型执行。在“执行记录”查看当前节点、员工状态和待审批命令。
5. 逐次检查并批准方案声明的命令。Todo 示例使用 `node --test todo.test.mjs` 和 `node --test acceptance.test.mjs`；审批绑定请求所列文件版本，文件变化后需重新核对。实际退出码、完整测试输出和失败记录可在“真实测试结果”展开查看；验收核对的是已接受交付文件的 SHA，旧成功或迟到回执不会自动变为当前成功。

## 停止与恢复

停止项目使用执行页的“停止运行”。失败或停止后，先点击“刷新审批与交付”，查看原因、原生操作回执和已有文件，再点击“检查恢复条件”。恢复会重新核对原批准版本、文件 SHA、完整 DAG、预算、调用次数、权限和未知操作。

“恢复未完成任务”保留已核验完成节点；“完整重试”重做全部节点，仍使用原方案的历史调用及费用上限。模型未知费用可以显式选择“保留未知费用预留，在原预算继续”，预留继续占用预算；这不会把费用结算为零，也不会确认外部操作。命令结果未知时先核对本机及迟到回执，再决定后续行动，不直接重放。

遇到输出截断、上下文或任务预算不足时，查看失败原因，回到项目让 AI 重新生成候选并确认。旧 Run 的恢复继续使用旧批准方案和原额度，重新生成方案不会改变旧运行的历史。

方案校验提示“任务产物输入不能同时指定来源任务和固定 SHA256”时，让 AI 重新生成方案：本次员工将要生成的文件只绑定来源任务，实际版本由验收交接记录确认；已有外部导入文件才固定 SHA。不要删除旧运行的文件、修改数据库或给旧合同换 SHA 来绕过检查。已通过的旧测试保留，新的方案需重新批准和执行。

调整说明支持最多 4000 字符；费用预检不会调用规划模型。点击生成时会再核对一次最新费用，若费用或参数变化，先查看更新后的预检再确认生成。界面若提示请求结果未知，保留原请求并使用“继续获取回复”，避免重新提交新的请求。

本轮按配置单价和实际 Token 回执保守登记费用，Go 使用峰时完整输入费率；缓存折扣、时段折扣和订阅账单以提供商为准。历史未知费用保持未核对状态。本机命令需要审批和文件版本匹配；当前本机执行器使用同一 Windows 用户权限，不提供独立操作系统沙箱。

知识资料需先在网页授权给员工，再纳入确认方案。运行固定资料版本，编辑新版本不会替换旧运行的引用。Todo 本身使用内存数据，结束 Todo 进程会丢失 Todo 记录；项目的任务、文件、预算与追溯独立保存在工作台数据目录。
