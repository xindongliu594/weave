# 混合检索隔离比较计划

用户已同意继续比较，尚不切换生产检索。本轮先复用现有 Transformers/E5/pgvector及Meilisearch官方自供向量接口，不新增生产检索框架。

1. 使用部门原获授权的两份验收方法固定v1及SHA，正文仅存本轮私有隔离目录；以此前8份合成中文主题资料另做诊断，不把它们冒充公司资料。真实公司业务知识覆盖目前不足，最终据实说明。
2. 先定义查询与预期：原词、同义改写、混合术语、完全无答案、越权与旧版。公司资料和合成资料分别统计，不用两份文档的Top6召回率冒充全面精度。关注Top1/MRR、返回结果精度、无答案误命中。
3. 同一模型/正文/版本下比较原关键词、Meili严格关键词、现有本地向量/融合和Meili原生混合；预先固定混合权重，不挑最好一条结果当结论。计时包含本地查询向量生成；冷启动和索引生成另列。
4. 在隔离数据库/索引中加入更相近的未授权资料、同ID新版本与归档来源，先过滤批准版本集合，再排名；校验返回片段的ID、文档、版本、正文及来源哈希。固定资料丢失须拒绝而不是换新版。
5. 不以距离或rankingScore冒充答案正确率。向量检索必返回相近资料时，如无答案误命中增加，明确记录；不在同一测试集上调阈值再宣称通过。
6. 保存结果、软件及模型哈希、诊断源码、限制和清理证据。下载组件、临时模型/索引仅在本轮目录；无付费模型调用，旧费用/权限/知识配置保留。

官方接口：[Meilisearch自供向量](https://www.meilisearch.com/docs/capabilities/hybrid_search/how_to/search_with_user_provided_embeddings)。本地模型沿用 services/embedding/model-lock.json 固定版本及SHA，不追随在线最新模型。
